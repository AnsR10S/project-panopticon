# Prompt-alternatives V2 — exploratory protocol

This is a new prompt/model cohort, not a continuation of the historical V1 pricing run. It retains the three-firm Calvano market, simultaneous frozen decisions, declared memory window, hidden-horizon candidate, truthful next-round notices and gross-profit endpoint. It makes no claim that improved wording produces strategic competence or collusion.

The two new profiles share their system and price-only action instructions. `qualitative_v2` describes directional demand effects. `explicit_economics_v2` additionally includes the exact equation/parameter block from the existing `explicit-economics.txt`. The original `explicit_economics`, `price_only`, and other historical profiles remain unchanged and selectable. New qualitative/explicit profiles do not suggest an easy heuristic, a coordination policy or a competitive/joint target price. Historical prices remain authorized observations, including the initial seeded record.

For the default parameters, the explicit block implements `q_i=exp((200-p_i)/25)/(1+sum_j exp((200-p_j)/25))` and `profit_i=((p_i-100)/100)*q_i`. The code substitutes configured parameters rather than hardcoding these values as recommendations. Displayed own share among sellers differs from quantity including the outside option. Own currency profit and price ticks are labelled separately.

V2 table history preserves the same outcome fields and one-decimal share/four-decimal financial precision as prose/compact history: round, own price, all completed prices in firm order, own share among sellers, own gross, deduction and net. It does not reproduce a previous bare price as reasoning. Firm-private strategy notes appear only under the existing explicit private-note profile and remain bounded/latest-only; they are written self-reports, not verified latent reasoning. Raw responses and full numerical outcomes remain archived.

The new notebook defaults to explicit knowledge, table history and GPT-5.6-sol for AgentRouter. `AGENTROUTER_MODEL` selects GPT-6.1-sol, GPT-5.6-sol or GPT-6-astra and updates the visible editable accounting-rate assumptions. Model changes alter the study population. Live latency probes did not establish a speed advantage for GPT-5.6-sol, and Astra was rate-limited. Keep Responses: the gateway rejected Chat for the two tested candidate models.
