## Research phases after the software release

R1: select available provider/model and pilot budget; verify real request/usage
behavior and strategic consistency. R2: investigate auditor thresholds and
economic/prompt sensitivity on separate pilot data. R3: choose the primary
window, minimum effect, independent run count, failure policy, and inference;
freeze protocol/configs and disclose preparation. R4: execute randomized
confirmatory work, retain all attempts, analyze results, and write the paper.

The dated original conversation's schedule is historical. These phases use
acceptance evidence rather than pretending a planned date proves completion.
