# Paper workspace

The V1 software release is not a completed competition paper. The historical
22-page architecture handoff remains under `docs/source-materials`. Use the
current official event template when actual experiments have been performed.

Maintain source, bibliography, and exports here. Tables/figures in a real paper
must identify their run IDs, analysis revision, protocol/config hashes, and
failure counts. Do not use the original fictional bar chart or the new scripted
engineering demonstration as empirical LLM evidence.

The [paper outline](outline.md) lists the intended content. [References](references.bib)
contain source identifiers; check full bibliographic details before submission.
